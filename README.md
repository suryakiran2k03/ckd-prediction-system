# Chronic Kidney Disease Prediction System

## Overview

The Chronic Kidney Disease Prediction System is a healthcare-focused web application developed using ASP.NET and C#. The system helps predict Chronic Kidney Disease based on patient data while providing role-based access for administrators, doctors, receptionists, and patients.

## Features

* Role-based authentication
* Admin dashboard
* Doctor management module
* Patient management module
* Receptionist module
* CKD prediction functionality
* Database integration

## Technologies Used

* ASP.NET
* C#
* SQL Server
* HTML
* CSS
* JavaScript
* ## Modules and Responsibilities

### Admin Module

* Manage doctors, patients, and receptionists.
* Monitor system activities.
* Maintain overall system administration.

### Doctor Module

* View patient information.
* Analyze patient records.
* Assist in CKD prediction and diagnosis.

### Receptionist Module

* Register new patients.
* Manage appointments and patient records.
* Coordinate communication between patients and doctors.

### Patient Module

* View personal information.
* Access diagnosis and prediction results.
* Track healthcare-related records.
